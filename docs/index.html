Viral Shorts Pipeline

Viral Shorts Pipeline is a private, personal tool that runs on its owner's own computer. It finds short newsworthy moments in publicly available videos, edits them into vertical Shorts, and uploads them to the owner's own YouTube channel.

The app is not offered to the public. Only the owner signs in, and only the owner's own YouTube channel is used.

What it does with Google

It uses the YouTube Data API to upload Shorts to the owner's channel, read the channel's recent uploads so nothing is posted twice, and read view counts of those uploads so it can learn which topics viewers like.
